OmniSync passwords

Synced, end-to-end encrypted, between Zen and Brave. Separate from each browser's built-in password manager.

The vault is locked.

Autofill is off on websites. OmniSync needs permission to run on websites to fill and capture passwords.

Import from your browser

Extensions can't read a browser's built-in password store, so bring your passwords over once with the browser's own export:

  1. Brave: open brave://password-manager/settings → Export passwords.
  2. Zen: open about:logins → ⋯ menu → Export Passwords.

Delete the exported CSV afterwards. It contains every password in plain text.
