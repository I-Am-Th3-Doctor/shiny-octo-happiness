Rule: every app gets its own assigned action. Moves repeat by type across apps (16 move types below); the assignment is per-app and keyed by app component, so any single app's move can be changed later without touching the others.

(?) = label truncated or uncertain in the screenshot — Jay to confirm/correct.

## Move vocabulary

- **ring** — rapid small side-to-side shake, like a ringing phone or bell
- **spin** — full 360° rotation
- **shutter** — quick scale-down + pop, like a camera shutter
- **bounce** — vertical bounce
- **swing** — pendulum swing from the top edge
- **flip** — horizontal flip
- **pop** — quick scale pop
- **wobble** — loose side-to-side wobble
- **pulse** — gentle scale breathing
- **slide** — slides sideways and back
- **drop** — drops from above with a small bounce (pin drop, money drop)
- **chat** — speech-bubble pop (messaging)
- **tick** — short step/tick motion (clock, auth codes)
- **wave** — gentle tilt wave (sound, signal)
- **flash** — quick brightness flash
- **zoom** — scales toward the viewer and back

## Notes for the builder

- The mapping is keyed by app component, not by icon file — a move assigned to an app plays no matter which icon artwork is showing for that app.
- If an app is added to the phone later and has no entry here, give it a generic move.
- Any single app's move can be changed in this file without touching the others.

## How Searchlight reads this file

This file is part of the icon theme (`app/src/main/assets/icontheme/`). Searchlight reads the
table above when it starts; change a row, rebuild, and that one app's move changes.

- **Component** is the app's package (or one exact `package/activity`), in backticks; list
  several, comma-separated, for the same app on different phones. Every launcher icon of that
  app makes the row's move.
- An app no Component names is found by its **App** label instead (as the launcher shows it;
  "(?)", "(1)" and "(2)" are ignored, and capitals don't matter). The move is then remembered for
  that app's component, like any other.
- A label cut short with "..." matches apps whose label starts with what's left, when that's at
  least four letters ("Moto ..." matches a label starting "Moto"), and only apps no other row
  matched.
  Shorter stubs ("Fi...", "O...", "U...", "V...") can't name one app, so they match nothing
  until a Component or the full label is filled in.
- **Action** is one of the 16 moves above. An app with no row, or a row whose action isn't one
  of them, gets a generic move (spin, swing, bounce or flip, always the same one for that app).
- A move given on a line of `theme.txt` (next to an icon file) wins over this table.
- Moves belong to the app, not to the icon file: they play on whatever icon shows for it, the
  theme's, an icon pack's, or the system's.
