# Searchlight icon theme
# ======================
#
# Every icon in this folder (app/src/main/assets/icontheme/) is a 192x192 PNG (xxxhdpi) with a
# transparent background. The starter set is drawn as glossy 3D objects: each one a soft, raised
# object in the app's own colors, lit from the top, the same rounded depth and soft shadow below.
# Keep new icons in that style so the set stays one family. (tools/icontheme/make_icons.py draws
# the starter set; your own artwork can simply replace any of its files.)
#
# Naming: lowercase letters, digits and underscores, ending in .png, named after the app
# (spotify.png, google_keep.png).
#
# To add an icon:
#   1. Drop the PNG into this folder.
#   2. Add one line below:   <app>  <file>  <move>  [clock|calendar]
#   3. Rebuild Searchlight.
# To swap one of the starter icons for your own: replace its PNG (same name), rebuild.
#
# <app> is the app's package (every launcher entry of that app, e.g. com.spotify.music), or one
#   exact component (package/activity, e.g. com.android.settings/.Settings), which wins over its
#   package. List the same file on several lines for the same app on different phones (a Pixel's
#   and a Galaxy's dialer, say).
# <file> may be "-": no art of its own, only a move for that app (for an icon a pack draws, say).
# <move> is how the app's icon comes alive on Home. It belongs to the app, not to the file: it plays
#   on whatever icon shows for that app, this theme's art or an applied icon pack's. Apps a pack
#   draws that have no line here get one of the generic moves (always the same one for that app).
#   Apps showing their plain system icon stay still.
#   generic moves:   spin, swing, bounce, flip
#   signature moves: record  (spins like a record on a turntable)
#                    ring    (rings like an alarm bell)
#                    shutter (clicks like a camera shutter)
#                    gear    (turns a notch like a cog)
#                    drop    (drops in and lands, like a pin)
# The optional last word makes an icon live, drawn over its PNG by Searchlight:
#   clock     the current time, hour and minute hands, every minute (10:10 when animations pause)
#   calendar  today's date: the day on the page, the month on the band; it turns over at midnight
#
# With an icon pack applied (Settings > Icon pack), the pack's icons replace this theme's art; the
# live clock and calendar stay Searchlight's own, and apps the pack doesn't draw keep their system
# icon.
#
# Lines starting with # are notes.
