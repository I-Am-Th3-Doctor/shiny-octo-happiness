# Searchlight icon theme
# ======================
#
# This folder (app/src/main/assets/icontheme/) is the theme: your icon files and this mapping.
# It ships with no icons of its own: every app shows its system icon until you add yours here.
#
# Icons you add
# -------------
# Size and format: 192x192 PNG (xxxhdpi), transparent background.
# Style, so the set stays one family: glossy 3D objects. Each icon is a soft, glossy, raised
#   3D object in the app's own colors, lit by the same light from the top, with the same rounded
#   depth.
# Naming: lowercase letters, digits and underscores, ending in .png, named after the app
#   (spotify.png, google_keep.png).
#
# To add an icon:
#   1. Drop the PNG into this folder.
#   2. Add one line below:   <app>  <file>  [<move>]  [clock|calendar]
#   3. Rebuild Searchlight.
# To swap an icon: replace its PNG (same name) and rebuild.
#
# The lines
# ---------
# <app> is the app's package (every launcher entry of that app, e.g. com.spotify.music), or one
#   exact component (package/activity, e.g. com.android.settings/.Settings), which wins over its
#   package. Give the same file on several lines for the same app on different phones (a Pixel's
#   and a Galaxy's dialer, say).
# <file> is the icon's PNG here, or "-" for none: the app keeps its system icon (or the applied
#   pack's).
# <move> is optional. Every app's move on Home is set in searchlight-icon-actions.md, in this
#   folder (one row per app, keyed by its component; the 16 moves are listed there). A move here
#   wins over that table for this one app: ring, spin, shutter, bounce, swing, flip, pop, wobble,
#   pulse, slide, drop, chat, tick, wave, flash, zoom (or "-" for the table's).
#   The move belongs to the app, not to the file: it plays on whatever icon shows for that app
#   (yours, an icon pack's, or the system's). An app in neither file gets a generic move (spin,
#   swing, bounce or flip, always the same one for that app).
# The optional last word makes the icon live, drawn by Searchlight itself (any file is ignored):
#   clock     a clock face with the current time, hour and minute hands, every minute
#             (a still 10:10 while animations pause)
#   calendar  today's date: the day number, and the month where there's room; it turns over at
#             midnight
#
# With an icon pack applied (Settings > Icon pack), the pack's icons replace the icons here; the
# live clock and calendar stay Searchlight's own, every app keeps its move, and apps the pack
# doesn't draw keep their system icon.
#
# Lines starting with # are notes.

# The clock: a live face (its move, tick, is in searchlight-icon-actions.md)
com.google.android.deskclock          -    -    clock
com.sec.android.app.clockpackage      -    -    clock
# The calendar: today's date, live
com.google.android.calendar           -    -    calendar
