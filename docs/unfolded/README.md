# Unfolded (Razr Fold inner screen)

CI screenshots (Screenshots #58/#59). "Unfolded" is the emulator display resized to
1840×2208 @ 420dpi (~700dp wide); there's no Razr Fold emulator.

- `tile-row.png`: the card's tiles side by side (normal and 1.3× text). Text that doesn't fit
  ends in "…" here because CI runs with animations off; on the phone it scrolls (marquee).
- `unfolded-screens.png`: the 7-column widget grid (edit mode), results capped and centered,
  the app table in 7 columns.
- `folded-unchanged.png`: folded home, edit mode, search and app table, as before.
